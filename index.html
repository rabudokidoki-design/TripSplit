🔧 Firebase Setup (1 min, free, no credit card)

  1. Go to console.firebase.google.com → Create project (e.g., trip-split) → Disable Google Analytics → Create
  2. Left menu → Build → Firestore Database → Create database → Start in test mode → Choose location (asia-southeast1) → Enable
  3. Top left ⚙️ → Project Settings → General → Your apps → Web </> → Register app `trip-split` → Copy the firebaseConfig object
  4. Open this HTML file in notepad → Replace the placeholder config at top (YOUR_API_KEY etc.) with your real config → Save
  5. Host file: Go to https://app.netlify.com/drop → Drag this HTML file → You get permanent link `https://xxx.netlify.app` → Share with friends
  6. Firestore Rules (optional secure): In Firestore → Rules → Paste: 
    rules_version='2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /trips/{tripId} {
      allow read, write: if true;
      match /expenses/{expId} {
        allow read, write: if true;
      }
    }
  }
}
    Then Publish. For production, add password check in rules.

Why Firebase? No Python server needed, real-time sync for all friends, data persists forever even if site closed, free tier 50k reads/day enough for trips, no credit card.
